# Project Documentation

This directory contains project documentation and decision records.

## Documentation Areas

- `phase-0/` contains the approved baseline required before application feature work begins.
- `adr/` contains architecture decision records for significant technical choices.

## Documentation Rules

- Keep documentation close to implementation decisions.
- Update documentation when product scope, architecture, data model, security, operations, or delivery expectations change.
- Do not use documentation to justify speculative application code.
- Record major technical decisions before implementing them.
